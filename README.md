🌌 Nature Photography Gallery

A clean, aesthetic photo gallery website for sky and nature photography. Images appear immediately after upload, and the project owner can delete images using a hardcoded login. Fully client-side — no backend required.

✅ Features

Immediate Upload – Images appear in gallery instantly.

Owner-Only Delete – Only the project owner can delete images via a secure hardcoded login.

Client-Side Storage – All images and metadata stored in localStorage.

Beautiful Backgrounds – BG2.webp for public pages, BG3.png for owner dashboard.

Transparent Upload Form – Sleek, modern design for upload page.

Modal Preview – Click images to see details and delete option (owner only).

🌐 Pages

Owner Dashboard (owner.html)

Displays all uploaded images with delete buttons

Background: BG3.png

🛠️ Usage

Open index.html in your browser.

Fill the upload form, check the rules box, and submit an image.

Click View Gallery to see uploaded images.

In the owner dashboard, delete any image as needed.
