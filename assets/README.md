# Media Files Required

This folder should contain the following media files:

## 1. BG.mp4 (Required)
- **Purpose:** Looping background video for the upload page
- **Recommended specs:**
  - Resolution: 1920x1080 or higher
  - Format: MP4 (H.264 codec)
  - Duration: 10-30 seconds
  - Theme: Sky/nature scenery (clouds, sunset, ocean, mountains, etc.)
  - File size: Keep under 20MB for fast loading

### Where to find free videos:
- [Pexels Videos](https://www.pexels.com/videos/) - Search for "sky timelapse" or "nature"
- [Pixabay Videos](https://pixabay.com/videos/) - Search for "clouds" or "sunset"
- [Coverr](https://coverr.co/) - Free stock video footage

## 2. BG2.webp (Required)
- **Purpose:** Static background image for the gallery page
- **Recommended specs:**
  - Resolution: 1920x1080 or higher
  - Format: WebP, JPEG, or PNG (WebP preferred for smaller file size)
  - Theme: Soft, calming nature scene
  - Colors: Light, pastel tones that won't interfere with gallery images

### Where to find free images:
- [Unsplash](https://unsplash.com/) - Search for "sky gradient" or "nature background"
- [Pexels](https://www.pexels.com/) - Search for "pastel sky" or "soft clouds"
- [Pixabay](https://pixabay.com/) - Free stock photos

### Converting to WebP:
You can convert JPEG/PNG to WebP using:
- Online: [CloudConvert](https://cloudconvert.com/jpg-to-webp)
- Command line: `cwebp input.jpg -o BG2.webp`

## Quick Start

1. Download your chosen video and image
2. Rename them to `BG.mp4` and `BG2.webp`
3. Place them in this `assets/` folder
4. Refresh your website

**Note:** The website will still function without these files, but the backgrounds won't display properly.
